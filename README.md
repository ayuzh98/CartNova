# 🛍️ About CartNova

**CartNova** is a modern, responsive e-commerce website developed as a college project.

The project is designed to provide users with a simple, attractive, and user-friendly online shopping experience.

Users can browse products, search and filter products, view detailed product information, add products to their cart, manage their profile, and proceed through the checkout process.

CartNova is being developed with a **frontend-first approach**, with a Java Spring Boot backend and MySQL database planned for the next development phase.

> **Shop Smart. Live Better.**

---

# 🎯 Project Objective

The main objective of CartNova is to design and develop a complete e-commerce platform that demonstrates modern web development concepts.

The project focuses on:

- Creating a clean and responsive user interface
- Providing smooth navigation between pages
- Implementing product browsing and filtering
- Creating an interactive shopping cart
- Designing user authentication pages
- Providing an order management interface
- Creating an admin dashboard
- Building a scalable structure for future backend integration
